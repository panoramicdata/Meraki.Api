Remarks

The server wraps results as {"result":{"type":"success","capability_id":"...","data": ... }}. This property is the data element alone, which is the shape the equivalent MerakiClient call returns, and is therefore what you almost always want. Null when the response carried no recognisable envelope, in which case RawJson is already the payload.

The payload to work with: DataJson when the envelope was recognised, and RawJson otherwise.
